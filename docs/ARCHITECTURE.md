# 코쓱이를 지켜줘 (Mission: Zero Noise) — 서비스 구조

> 국민대 차세대통신 사업단 축제 부스 게임. AWS / 5G / 통신 키워드를 학생이 자연스럽게 학습하도록 설계한 대화형 퀴즈.

---

## 1. 한 줄 요약

학생(요원)이 부스에 비치된 노트북에서 **AI 캐릭터(코쓱이)와 대화하며 3개 키워드를 추리**, 마지막에 리부트 코드를 입력해 시스템을 복구하면 점수와 함께 랭킹에 등재되는 **싱글플레이어 웹 게임**입니다.

---

## 2. 기술 스택

| 레이어 | 기술 | 비고 |
|--------|------|------|
| **프론트엔드** | Vanilla JavaScript SPA, HTML5, CSS3 | 라이브러리·번들러 없음. 정적 파일로 서빙. |
| **백엔드** | Node.js 22 + Express 4 | REST API. ~10개 엔드포인트. |
| **데이터베이스** | SQLite (better-sqlite3) | 단일 파일 기반. players / sessions / messages 3개 테이블. |
| **AI** | Groq Llama 3.3 70B → gpt-oss-120b → Gemini → Llama 8B (4단계 폴백) | 모두 무료 티어 사용 중 |
| **인프라** | AWS EC2 (단일 인스턴스, 32.197.64.211, port 80) | 멘토님 제공 계정. nginx/PM2 없이 node 직접 실행. |

## 4. 게임 진행 플로우 (사용자 1명 기준)

```
랜딩 페이지 (이름·전화번호·동의)
     ↓
인트로 브리핑 (4 패널 타이핑)
     ↓
게임 시작 (3분 타이머, 노이즈 100%)
     ↓
┌─────────────────────────────────────┐
│ Phase 1 — 글로벌 파트너 기업 (정답: AWS) │
│   • 코쓱이와 자유 대화 (AI 호출)        │
│   • 정답 키워드 입력                    │
└─────────────────────────────────────┘
     ↓ (정답 시)
┌─────────────────────────────────────┐
│ Phase 2 — 통신망 기술 (정답: 5G)         │
└─────────────────────────────────────┘
     ↓
┌─────────────────────────────────────┐
│ Phase 3 — 사업단 명칭 (정답: 통신)        │
└─────────────────────────────────────┘
     ↓
┌─────────────────────────────────────┐
│ Phase 4 — 리부트 코드 "AWS 5G 통신"      │
└─────────────────────────────────────┘
     ↓
결과 화면 (점수, 랭킹, AWS 양자통신융합전공 혜택 안내)
```

**점수 공식**: `1000 - (총 턴수 × 10) - (경과초 × 1.5)`
→ 빠르게 + 적은 대화로 클리어할수록 고득점.

## 5. AI 사용량 분석

### 한 게임 세션당 (예상치)

| 항목 | 값 |
|------|----|
| 평균 자유 대화 횟수 | 5~15회 |
| 정답 시도 횟수 | 3회 |
| 리부트 코드 입력 | 1회 |
| **AI 호출 총 횟수** | **5~15회** (정답·리부트는 AI 호출 없음) |
| 호출당 입력 토큰 | ~3,000 (캐릭터 프롬프트 + 페이즈 가이드 + 대화 히스토리) |
| 호출당 출력 토큰 | ~200 (코쓱이 응답 1~3문장) |
| **세션당 총 토큰** | **~16,000 ~ 48,000** |

### 부스 운영 시 예상 부하 (보수적 추정)

| 시나리오 | 동시 활성 | 시간당 세션 | 시간당 AI 호출 | 시간당 토큰 |
|---------|---------|----------|------------|-----------|
| 평상시 | 3명 (노트북 3대) | ~30 | ~300 | ~1,000,000 |
| 피크 (점심시간) | 3명 | ~60 | ~600 | ~2,000,000 |

**8시간 행사 누적**: 세션 약 **300~500회**, AI 호출 약 **3,000~5,000회**, 총 토큰 약 **10M~16M**.

## 7. AWS Bedrock이 해결해주는 것

### 적합한 모델
- **Claude 3.5 Haiku** 또는 **Claude 3 Haiku** (한국어 품질 우수, 응답 빠름)
- **Nova Lite / Pro** (저비용, AWS 네이티브)

### 예상 비용 (Claude 3.5 Haiku 기준)
- 입력: $0.80 / 1M tokens
- 출력: $4.00 / 1M tokens
- 행사 1회 (16M 토큰, 입출력 비율 약 95:5):
  - 입력 15M × $0.80 = **약 $12**
  - 출력 1M × $4.00 = **약 $4**
  - **총 약 $16 (한화 ~22,000원)**

> Nova Lite는 더 저렴 ($0.06 입력 / $0.24 출력 per 1M) → **행사 1회 ~$1.5 (~2,000원)** 수준.

### 현재 구조와의 통합
- `server/services/aiService.js`의 폴백 체인에 `callBedrock()`이 이미 구현되어 있음 ([server/services/aiService.js:127-159](../server/services/aiService.js#L127))
- IAM 자격 증명만 받으면 즉시 1순위로 전환 가능 (코드 변경 최소)

## 8. 데이터 / 보안

### 수집 정보
- **요원명** (1~20자)
- **전화번호** (우수 참여자 보상 추첨용, 개인정보 동의 필수)

### 저장 위치
- EC2 인스턴스 `/home/ec2-user/game/data/game.db` (SQLite)
- 파일 권한 600, 디렉터리 700

### PIPA 준수
- 사전 동의 체크박스 (필수)
- 수집 항목·목적·보유 기간(1개월) 명시

### 미적용 (한계)
- HTTPS 미적용 (HTTP 평문) — 부스 내 폐쇄 환경이라 이번 행사는 감수
- 보안 헤더 (helmet), Rate Limiting 미적용

## 10. 멘토님께 드리는 요청 (협의 사항)

1. **AWS Bedrock 사용 가능 여부** — Claude Haiku 또는 Nova 모델
2. **예상 비용 수준이 허용 범위인지** (Claude Haiku ~$16, Nova Lite ~$1.5 / 1회 행사)
3. 만약 어렵다면 **다른 대안**(예: Bedrock On-Demand 일일 한도 설정, EC2 내 sLLM 등) 추천 의견
